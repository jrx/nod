Browse the custom app connections included in Nod.

These apps use the same Apps entry and private connection setup. Open an app page for setup requirements, example requests, limits, source files, and a social preview image.

<AppCatalog />

The catalog is generated from the same app folders that Nod loads. It lists shipped definitions and does not report live provider health.

## Add your app

Community contributors and partners use the same format and required tests. Add a folder, complete the checks, and submit a PR for maintainer review.

Start with [Build an app for Nod](/contribute/apps/), or use [the AI builder skill](/contribute/apps/build-with-ai/).

Composio supplies the wider app catalog in Nod. See [Connect apps](/connect/apps/) for those connections.

# agent-desktop

Computer use runs agent-desktop 1.3.1 by Vercel Labs, from the npm package `agent-desktop` (https://github.com/vercel-labs/agent-desktop). It is licensed under the Apache License, Version 2.0, the same license text as the application's root `LICENSE` file shipped with the engine. agent-desktop is provided without warranty.

The app includes the published binaries without source changes: on macOS `agent-desktop` and `agent-desktop-macos-helper` in `Contents/Helpers`, signed as part of the application; on Windows `agent-desktop.exe` and on Linux `agent-desktop` and `agent-desktop-linux-clipboard-owner`, in `resources/agent-desktop`.
